Strategic Vision

The Challenge & The Solution

Transforming fragmented applications into a single unified Super App ecosystem.

⚠️

The Fragmented Dilemma

  • ✕ Users forced to install and manage dozens of separate standalone government & financial apps.
  • ✕ Inconsistent authentication, security postures, and variable privacy compliance.
  • ✕ Slow partner onboarding with manual code merges and risky release cycles.
✨

The Unified Super App Solution

  • ✓ One App for All Services: High-performance Flutter container running modular Mini Apps on demand.
  • ✓ Automated Pre-Flight Gates: Network isolation, domain verification, and SAST compliance.
  • ✓ Self-Service Backoffice: Instant registration, live status monitoring, and version governance.
Architecture

4 Flexible Integration Tiers

Supporting any partner technology stack with zero manual host app modification.

1. WebView Mini Apps

H5 / WEB

Interactive responsive web applications running inside a sandboxed Web container with secure bidirectional SuperAppJSBridge and hardware capability access.

2. Flutter Package

SOURCE / ARTIFACT

High-performance in-app micro-apps integrated via Git Repository source OR Hosted Dart Pub Artifacts from Sonatype Nexus CE with offline caching and native transitions.

3. Native SDK Frameworks

AAR / XCFRAMEWORK

Platform-specific binary modules integrated automatically via Native SDK Codegen and Universal Native Launcher without manual mobile codebase edits.

4. Deep Link & App Links

OS URL SCHEME

Seamless OS-level URL scheme delegation (e.g. cambodia-tax://) to external standalone applications with automated Store fallback routing.

Automated Assembly

CI/CD Pipeline, Codegen & Nexus CE

Release-mode compilation with Jenkins, Sonatype Nexus Repository CE, and automated SDK codegen.

STAGE 1: TEST BUILD

Test Release Assembly

Compiles signed test release APKs uploaded to apk-test-builds and updates Web Sandbox container for QA validation.

STAGE 2: PRODUCTION

Production Packaging

Produces hardened production APKs with ProGuard minification, release signing, and direct upload to apk-releases.

NEXUS REPOSITORY CE

Sonatype Nexus CE

Hosts private Dart pub packages (dart-pub-hosted) and raw release binary repositories with checksum verification.

⚡ Automated Native SDK Codegen & Zero Mobile Git Mutation:

NativeSdkCodegenService dynamically generates launcher glue code and injects Gradle/CocoaPods dependencies in isolated runners, keeping the main repository completely clean.
